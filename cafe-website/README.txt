BOSS CAFE - HOW TO RUN
1. The pages load data with fetch(), so open the folder with a local server:
   - VS Code: install "Live Server", right-click index.html > Open with Live Server
   - or run:  python -m http.server 8000   then open http://localhost:8000
2. Replace VIDEO_ID in index.html with your YouTube video ID.
3. Put your own photos in assets/images/ and set "image":"assets/images/yourfile.jpg" in data/products.json.
4. Edit the cafe name, address and phone number in each HTML file footer/contact section.
